# 生产 Web 并发配置约定

2026-09-10 用户确认：**当前环境适合 3×4，后续常规发布均沿用此配置。**

## 固定基线

适用于当前腾讯云 4 vCPU / 8 GB 单机 ERPNext 部署，Web、MariaDB、Redis、队列和调度器共用服务器。3×4 表示 **3 个 Gunicorn Web 工作进程，每进程 4 个线程**，不包括 Gunicorn 主进程，也不代表 12 个 CPU 核或 12 名在线用户。

服务器 `/opt/hengsuan-erp/.env`：

```dotenv
GUNICORN_WORKERS=3
GUNICORN_THREADS=4
```

常规更新镜像、修复代码及重新部署均保留上述设置，不因内存空余、并发用户数增加或通用 CPU 核数公式而自动调大。后台队列进程的设置独立于这两个 Web 参数。服务器规格、服务拆分或主要业务负载发生明显变化时，再通过对照压测重新评估。

本目录 `.env.example`、`compose.yaml`、`start.sh` 以及 `accept-image.sh` 的默认值均为 3×4。既有服务器必须检查实际 `.env`，因为显式环境变量会覆盖默认值。当前运行镜像的内置默认值不因文档更新而改变；现网由显式环境变量保证 3×4，新构建镜像采用更新后的启动默认值。

## 选择依据

同一修复镜像 `hengsuan/erpnext:v16.33.0-hs.20260910.2`，源提交 `83bc3390487a0f691ad8df3502505c07d91e854b`；压测器保持在同一台服务器，业务数据规模及脚本不变，仅 Web 进程数由 3 改为 4，每进程始终 4 线程。

| 并发 | 3×4 P95 | 4×4 P95 | 3×4 请求/秒 | 4×4 请求/秒 |
|---:|---:|---:|---:|---:|
| 25 | 1.9 秒 | 1.8 秒 | 11.04 | 10.51 |
| 50 | 5.5 秒 | 6.8 秒 | 12.51 | 11.55 |
| 100 | 11 秒 | 14 秒 | 13.82 | 11.65 |
| 200 | 20 秒 | 21 秒 | 12.00 | 12.13 |

4×4 本轮混合请求 3,971 次、写入请求 1,685 次、登录 48 次，均无错误，但 50、100 并发的吞吐下降约 7.7%、15.7%，P95 上升约 23.6%、27.3%。高并发整机 CPU 平均约 94%～98%，可用内存仍超过 5 GB。清理数据后已恢复 3×4，健康检查通过。

这是采用模拟数据、同账号会话、每档 75 秒的单轮接口对照。任务组合和缓存状态存在波动，整机 CPU 包含压测器；结果支持当前选择，不证明所有负载下 4 个进程必然更慢，也不承诺实际在线员工上限。

本工作区完整报告及原始证据归档于 `outputs/release-20260910-2/cloud-loadtest-workers4/`，该目录不纳入 Git；本文件保留可随仓库交付的决策依据。
