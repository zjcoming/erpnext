# 工厂 ERP 项目需求访谈清单

> 访谈目标：确认客户真实业务流程、核心痛点、一期实施范围和验收标准。  
> 建议时长：60-90 分钟。  
> 访谈原则：先问“现在怎么做、哪里会失控”，再讨论系统功能。

## 一、企业与项目目标

- [ ] 公司主要产品、生产模式和主要客户类型是什么？
- [ ] 目前有多少员工、部门、工厂、仓库和生产线？
- [ ] 当前使用哪些软件、Excel 表格或纸质单据？
- [ ] 为什么现在考虑上线 ERP？
- [ ] 目前最严重的三个管理问题是什么？
- [ ] 老板希望上线后首先看到哪些变化？
- [ ] 本项目最重要的目标如何排序？
  - [ ] 提高交付准时率
  - [ ] 减少库存和资金占用
  - [ ] 减少缺料停工
  - [ ] 控制采购和生产成本
  - [ ] 掌握生产现场进度
  - [ ] 核算产品或订单利润
  - [ ] 规范审批和责任追踪
- [ ] 哪些结果出现后，可以认定一期项目成功？

## 二、销售订单与交付

- [ ] 客户询价、报价、合同、订单分别由谁负责？
- [ ] 订单从哪里进入系统？是否需要 Excel 批量导入？
- [ ] 产品是否存在型号、规格、颜色、尺寸等多属性？
- [ ] 同一订单是否允许分批生产、分批发货？
- [ ] 客户改单、插单、取消订单如何处理？
- [ ] 订单是否需要价格、信用额度或特殊条款审批？
- [ ] 交期目前如何计算和承诺？
- [ ] 老板如何知道订单当前做到哪一步？
- [ ] 是否需要订单延期预警？
- [ ] 发货是否需要装箱单、物流单号、签收或回单？
- [ ] 是否需要销售发票、收款和应收账款管理？

- [ ] 产品是否使用多级 BOM？
- [ ] BOM 是否存在版本、生效日期和审批流程？
- [ ] 是否允许替代料、可选料或客户指定物料？
- [ ] 不同客户的同一产品是否使用不同 BOM？
- [ ] 是否存在损耗率、边角料、副产品或联产品？
- [ ] 工艺变更后，旧订单和新订单如何区分？
- [ ] 谁负责维护和审核 BOM？

## 四、生产计划与工单

- [ ] 生产属于按订单生产、按库存生产，还是混合模式？
- [ ] 生产计划按天、周还是月制定？
- [ ] 是否需要由销售订单自动生成生产计划或工单？
- [ ] 是否需要合并多个订单集中生产？
- [ ] 是否存在拆单、插单、急单和排产调整？
- [ ] 是否需要按设备、产线、班组或人员排产？
- [ ] 工单是否包含工序、工时和标准产能？
- [ ] 是否需要车间报工、扫码开工和完工？
- [ ] 是否存在委外加工？
- [ ] 是否需要管理返工、报废、补产和生产损耗？
- [ ] 哪些生产异常需要通知管理层？

## 五、采购与缺料补充

- [ ] 当前由谁计算缺料？多久计算一次？

- [ ] 是否需要考虑现有库存、在途采购、在制品和安全库存？
- [ ] 是否有最小采购量、采购周期、整箱数量等限制？
- [ ] 物料是否有固定供应商或多个备选供应商？
- [ ] 是否需要询价、比价、采购审批？
- [ ] 采购价格是否需要历史价格和涨跌提醒？
- [ ] 紧急采购如何处理？
- [ ] 采购到货是否允许分批、超收、少收和退货？
- [ ] 是否需要来料质检，哪些物料必须检验？

## 六、仓库与库存

- [ ] 有多少仓库、库区、库位？
- [ ] 原料、在制品、成品、不良品是否分仓？
- [ ] 是否需要批次号、序列号、生产日期和保质期？
- [ ] 是否使用条码或二维码？
- [ ] 收货、领料、退料、补料、调拨、盘点分别由谁操作？
- [ ] 生产允许超领、少领或替代领料吗？
- [ ] 是否存在账面库存与实际库存不一致？
- [ ] 是否需要最低库存、安全库存和呆滞料预警？
- [ ] 是否需要客户提供物料或供应商寄售库存？
- [ ] 发货时是否需要扫码复核和先进先出？
