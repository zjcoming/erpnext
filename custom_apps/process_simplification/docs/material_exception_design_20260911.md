# 生产退料、报废与补料

## 业务规则

- 工人申请、主管审核、仓库过账。申请和审核不改变库存；未完成的申请占用数量。
- 新物料申请默认“补料后继续”，保留派工。明确选择“交回剩余任务”后，退库过账才释放受影响的未完成产量。历史申请保留原来的释放语义。
- 好料退回原发料仓；质量异常退料进入公司配置的待检隔离仓；确认报废进入工单报废仓（缺省使用公司默认报废仓）。仓库必须属于同公司、启用、非汇总，且不能等于在制品仓或误用正常发料仓。
- 库存事实按原发料来源扣减退料，退到隔离仓或报废仓也必须降低工单净发料量；转仓不等于物料需求消失。补发缺口再用可用库存及有效供应抵扣。
- 未过账申请可撤回，保留原申请和草稿作为审计记录，撤回草稿不能再提交。
- 取消已过账退库时，用反向派工记录恢复尚未重新派出的释放量，再回到已批准、待重新生成库存单。若释放量已重新派工，则禁止直接取消，提示保留原记录并按补料流程纠正，防止影响其他工人的任务与报工。

## 本次验收

覆盖公司报废仓兜底、缺配置提示、普通退料与报废的净缺口一致性、继续生产与交回任务两种模式、待处理撤回、大比例/全量退料取消与重做、已重新派工取消拦截、重复请求以及手机物料选择。

批次/序列号及库存质检仍由原生库存单校验；隔离后的放行、供应商退换、返工拆解与订单减产是独立业务，不通过本申请自动完成。正式重新派工仍遵循现有齐套约束。
