# 月度工资条打印

月度工资汇总列表顶部提供“打印工资条”。选择公司、工资月份和打印范围后，点击“打印”打开浏览器打印对话框。可以选择多名员工，也可以打印该公司该月全部可读取的汇总，后者不受列表分页影响。

在列表中先勾选同一公司、同一月份的汇总，会自动带入指定员工。单张月度汇总的“打印工资条”按钮也会带入当前员工。打印月份来自已有汇总，包含超过两年的历史月份。未生成汇总的员工不会出现在候选中。

工资条显示公司名称、月份、姓名、工号、计件金额、计时金额、工资合计、汇总状态和编号，不显示报工明细。金额直接读取已保存的汇总快照，币种来自公司。草稿标明“草稿 · 待确认”，已取消的汇总不可打印。此功能不重新计算工资、不刷新草稿、不确认工资、不记录付款。

版式为 A4 纵向，每页最多 5 条，员工之间提供虚线裁剪边界，单条避免跨页；公司或员工名称过长时允许自然增高。打印窗口保留“打印工资条”按钮，取消打印后可再次打印。浏览器阻止弹窗时会提示允许弹窗后重试。

打印接口复用工资管理角色与 Company User Permission 范围，同时通过 `frappe.get_list` 应用原生读取权限和工资汇总查询条件。指定员工为空、已取消、越权或不属于所选公司月份时拒绝打印，不能悄悄扩展为全部员工或少打印部分选中员工。

- 本次本地开发站点浏览器检查：工资列表入口、空选择拦截、两名员工多选及真实接口生成的工资条窗口、已确认汇总表单带入员工与历史月份；工资条金额与保存的汇总一致，屏幕版式无横向溢出。隔离站点另生成 7 人样张，HTML 按 5 + 2 分组；本次未复验 PDF 的物理分页或实物打印。
