# 恒算 ERP：仓库组授权与自动继承

日期：2026-09-22。代码基线：`rc/develop-v16` / `3574816f82`。

## 使用方式

进入“岗位与数据范围”，选择用户及公司，在“仓库与仓库组”中勾选负责的仓库组，保存岗位与范围。

- 仓库组包含全部下级分组和仓库。以后新增或移入该组的仓库，自动进入授权范围。
- 只负责一个仓库的人员，仍可单独勾选末级仓库；新增兄弟仓库不会跟随授权。
- 继承的行显示“继承自某仓库组”，不能在下级行单独取消。若只需部分子仓库，先取消组，再勾选具体仓库。
- 保存组授权时，仅记录组本身的授权规则；已被组覆盖的子仓库不再重复存储。
- 仓库移出某组后，按新归属及其他明确授权重新计算权限；公司范围与岗位权限继续生效。
- 已有的原生“仅组本身”授权会保留。页面提供“改为包含子仓库”操作，需要管理员明确选择后才扩展。
- 已停用且已直接授权的仓库仍显示，提示取消该授权后保存；不能新增停用仓库授权。

## 实现

权限保存沿用原生 `User Permission`，默认 `hide_descendants=0`，由 Frappe 展开当前树的后代。仓库组不作为实际收发存的记账仓库。

仓库新增、移组、停用状态变化、改名、删除触发仓库权限缓存失效。处理范围包含所有有 Warehouse 用户权限的用户；事务内、提交后和回滚后均清除对应缓存。成功提交后发送原生 `update_user_permissions` 事件，让在线客户端更新其权限数据。

本次没有数据库字段变更或权限数据迁移；现有正式用户的单仓库授权不会被自动换成组授权。
