# 订单工作台与生产工作台职责拆分设计

## 目标

把当前同时承担订单履约、库存预留、生产安排、缺料入口和发货动作的“订单履约总览”拆成两个老板工作台：

- `订单工作台`回答客户订单能否按时交付、当前卡在哪里、下一步由哪个环节处理。
- `生产工作台`回答必须生产什么、生产多少、是否已经安排、物料是否存在风险以及何时可能完成。

一期生产工作台只服务老板的生产决策和派单。工人的领料、开工、工序报工、完工及计件计时后续使用独立页面，当前继续由 ERPNext 标准单据承接。

## 设计原则

- 只修改 `custom_apps/process_simplification`，不修改 ERPNext/Frappe 官方源码。
- Sales Order、Stock Reservation Entry、BOM、Work Order、Stock Entry、Material Request、Purchase Order 和 Delivery Note 仍是唯一事实来源。
- 不新增人工维护的履约或生产状态台账；工作台状态从标准单据实时派生。
- 页面读取不创建单据；任何写操作均在服务端重新检查权限、订单状态、库存和未覆盖数量。
- 生产需求按 `Sales Order Item.name` 追踪，不能只按产品编码聚合。
- 默认排序以订单产品交期为第一优先级，同交期再按风险和未安排数量排序。
- 不使用 OpenSpec 管理本次设计或实施。

## 订单工作台职责

订单工作台纳入全部未履约完成的销售订单，包括库存足够、无需生产、可以直接发货的订单。

一级维度是 Sales Order，二级维度是 Sales Order Item。折叠行显示订单号、客户、最早交期、已发/订购、已预留/待交、生产中/生产缺口、最高风险和主要下一步；展开后显示产品级履约、成品覆盖和生产摘要。

订单工作台负责：

- 查看客户承诺、待交数量、有效预留、可直接发货数量和履约风险。
- 预留当前实际可用的成品库存。
- 为有效预留创建 Delivery Note 草稿。
- 查看标准 Sales Order。
- 通过“安排生产/查看生产”进入生产工作台并定位对应 Sales Order Item。

订单工作台不再负责：

- 创建或调整 Work Order。
- 展开详细 BOM 原料表。
- 直接进入缺料采购决策。
- 生产领料、开工、报工或完工。

## 生产工作台职责

生产工作台的主对象是一条 Sales Order Item 产生的生产需求，而不是 Work Order。Work Order 是该生产需求下面的执行记录。这样即使尚未创建工单，老板也能看到最高风险的“未安排生产”。

生产工作台纳入：

- 成品库存不能覆盖、存在生产需求的订单产品。
- 已有关联活动 Work Order 的订单产品。
- 部分完工但仍有剩余需求的订单产品。
- 已完工但成品尚未有效预留回来源订单的产品。

纯库存满足且没有活动工单的订单产品不进入生产工作台。没有 Sales Order 来源的活动工单放在“其他生产”分组，不混入订单交期主列表。

生产工作台负责：

- 按交期展示生产需求、已安排工单覆盖和未安排数量。
- 显示关联 Work Order 的数量、状态和已生产进度。
- 使用有效 BOM 展示原料库存、占用、在途供应及采购缺口。
- 创建或补建标准 Work Order，默认数量为当前未安排数量。
- 重新检查物料并进入独立的缺料采购页面。
- 将完工成品预留回原始 Sales Order Item。
- 打开标准 Work Order 处理修改、取消及生产执行。

生产工作台不负责：

- 客户价格、收款、信用或 Delivery Note。
- 自动选择供应商或直接创建 Purchase Order。
- 领料、开工、报工、完工和工人工资。
- 产能排程、甘特图、设备负荷或人工拖拽优先级。

## 统一数量口径

每个 Sales Order Item 使用以下计算：

```text
待交数量 = 订单库存单位数量 - 已发货库存单位数量

可用未分配成品 = 当前仓库可预留数量

成品覆盖 = min(
  待交数量,
  本订单行有效预留 + 可用未分配成品
)

生产需求 = max(待交数量 - 成品覆盖, 0)

活动工单剩余量 = sum(
  max(工单数量 - 已生产数量 - 工艺损耗数量, 0)
)

未安排生产 = max(生产需求 - 活动工单剩余量, 0)
```

有效预留和当前可预留数量不能重复计算。完工入库后，成品会先表现为可用未分配库存；预留回订单后转为本订单行有效预留。

## 状态与风险

状态和风险分开：状态说明当前步骤，风险说明延期可能。

生产需求主状态按以下顺序派生：

1. `master_data_blocked`：缺少有效 BOM、成品仓或生产仓基础资料。
2. `unplanned`：未安排生产数量大于零。
3. `material_shortage`：工单或生产需求已存在，但原料覆盖不足。
4. `ready_to_start`：生产已安排、原料无新增采购缺口、尚未开始。
5. `in_production`：存在已开始且未完成的工单。
6. `partially_completed`：已有完工数量且仍有生产需求。
7. `awaiting_order_reservation`：完工库存已能覆盖订单但尚未预留回订单。
8. `completed`：生产完成且已经回补订单，从默认列表退出。

风险等级：

- 红色：已逾期；临近交期但缺少基础资料或仍未安排。
- 橙色：七天内交付且缺料、生产未完成或存在生产缺口。
- 黄色：交期较远但存在缺料、未安排或异常。
- 绿色：生产计划覆盖且没有新增采购缺口。

没有交期的需求标记“缺少交期”高风险。页面不维护“待重新检查”业务状态；只显示数据更新时间，加载、刷新和写动作完成后重新查询。

## 生产工作台页面

顶部指标：待安排生产、已逾期生产、七天内到期、原料短缺、生产中、待回补订单。

筛选：订单/客户/产品搜索、交期范围、生产状态、风险等级、客户、只看缺料、只看未安排和其他生产。

折叠行显示：来源订单、客户、交期、产品、待交、成品覆盖、生产需求、工单覆盖、未安排、生产进度、物料摘要、状态、风险和主要操作。

展开后包含：

1. 数量关系：待交、有效预留、可用成品、成品覆盖、生产需求、工单覆盖、未安排、已生产和待回补。
2. 关联工单：工单号、状态、计划数量、已生产、剩余、BOM、仓库及查看标准工单。
3. BOM 物料风险：物料、单位、本需求贡献量、全部当前生产需求合计、仓库库存、已占用、本次可用、已转在制、未转采购申请、未到货采购、即时缺口和新增采购缺口。

物料库存可能被多个生产需求共享。页面必须明确显示“全部当前生产需求合计”和来源，不能把同一份库存分别宣称为每张订单独占。采购建议由缺料采购页面按选中需求重新聚合并复核。

## 操作逻辑

### 创建生产任务

从生产工作台执行。确认框显示产品、来源订单、交期、建议数量、BOM 和三个生产仓库。默认数量为未安排生产量。服务端重新计算后只允许创建不超过最新未安排量的标准 Work Order，并提交该 Work Order；缺料不阻止计划创建，缺 BOM 或仓库配置阻止创建。

### 处理缺料

生产工作台把 Sales Order 和 Sales Order Item 标识传给缺料采购页面。缺料采购页面重新按有效 BOM、仓库库存、未转 Material Request 和未收货 Purchase Order 计算采购缺口，只创建标准 Material Request，不自动创建 Purchase Order。

### 回补订单

完工后调用现有完工成品预留动作。服务端重新检查订单仍有效、待交数量存在、成品实际可用且不会超过待交量，然后创建标准 Stock Reservation Entry。

### 车间执行

领料、开工、Job Card、完工入库和取消工单只链接到 ERPNext 标准 Work Order/Stock Entry；一期不在工作台重复实现。

## 边界案例

- 多个工单覆盖同一订单产品：合计剩余量，只按未覆盖数量补建。
- 工单取消或停止：对应剩余量重新成为未安排。
- 工单超过需求：显示超计划生产，禁止继续创建但不自动取消标准工单。
- 销售订单取消或数量减少：停止新增动作；仍活动的关联工单显示来源异常，要求进入标准工单人工处理。
- 同一产品出现在不同订单：按 Sales Order Item 隔离，并按交期排序。
- 相同物料被多个需求共享：物料覆盖按当前选中需求整体计算并显示来源，不做隐式独占分配。
- 无 BOM：库存足够时只在订单工作台发货；库存不足时生产工作台显示基础资料阻塞。
- 多级 BOM：复用 ERPNext `get_bom_items_as_dict(..., fetch_exploded=1)`。
- 委外、服务和非库存产品：不进入简化生产工作台，提示使用标准流程。
- 多仓库：显示解析后的来源仓，不跨仓合并成可直接使用库存。
- 无销售订单工单：放在“其他生产”，只读展示并链接标准工单。
- 页面加载后库存或工单变化：写操作服务端拒绝旧数量并提示刷新。

## 响应式设计

桌面使用折叠列表和明细表格。小于 768px 时，订单、生产需求、工单和物料都转换为带完整标签的卡片，不依赖横向表格，不隐藏关键值；操作按钮单列显示并保持最小可点击高度。

## 验收标准

- 订单工作台仍显示库存足够、无需生产的待发订单。
- 订单工作台不再直接创建或查看详细生产工单，不再承载详细缺料处理。
- “安排生产”能进入生产工作台并定位 Sales Order Item。
- 生产工作台能显示尚未创建 Work Order 的生产需求。
- 纯库存覆盖且无活动工单的订单产品不出现在生产工作台。
- 生产需求按交期、风险、未安排数量和创建时间确定性排序。
- 生产需求展开后能解释成品覆盖、生产需求、工单覆盖、未安排量和 BOM 物料风险。
- 创建工单、处理缺料和回补订单在写入前重新检查标准单据。
- 桌面和移动端均能看清字段名称、数值和操作。
- 所有业务数据继续写入 ERPNext 标准单据，不新增自定义履约或生产台账。
